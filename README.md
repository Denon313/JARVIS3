# JARVIS 4.0 — GitHub Pages

نسخه بازطراحی‌شده جارویس برای GitHub Pages، با رابط RTL واکنش‌گرا، آیکون‌های SVG، اتصال API، ورودی صوتی مرورگر، ارسال تصویر به Gemini و ورود Google با Firebase.

## فایل‌ها
- `index.html` — رابط اصلی
- `styles.css` — طراحی واکنش‌گرا
- `app.js` — منطق چت، APIها، تصویر، تاریخچه و ورود
- `firebase-config.js` — تنظیمات عمومی Firebase
- `manifest.webmanifest` — فراداده نصب وب‌اپ

## انتشار در GitHub Pages
این فایل‌ها باید مستقیماً در ریشه شاخه‌ای قرار بگیرند که GitHub Pages از آن منتشر می‌کند (معمولاً `main` / `/(root)`).

## راه‌اندازی API
1. سایت را باز کن و از آیکون تنظیمات وارد «تنظیمات جارویس» شو.
2. ارائه‌دهنده را انتخاب کن: Groq یا Gemini.
3. API key همان سرویس را وارد کن.
4. «ذخیره تنظیمات و آزمایش اتصال» را بزن.
5. برای بررسی تصویر، Gemini را انتخاب کن و یک مدل بینایی‌پذیر را به کار ببر. برای جست‌وجو، گزینه جست‌وجوی وب Gemini را فعال کن؛ این قابلیت به پشتیبانی مدل/حساب و API بستگی دارد.

## امنیت
این پروژه صرفاً استاتیک است. کلید API در درخواست مرورگر استفاده می‌شود. اگر گزینه ذخیره کلید فعال شود، در localStorage نگهداری می‌شود و رمزنگاری‌شده نیست. برای محصول عمومی و چندکاربره، APIها را پشت یک backend امن قرار بده و محدودیت/سهمیه تعریف کن. هیچ کلید محرمانه‌ای را در فایل‌های عمومی قرار نده.

## Firebase
ورود Google به Firebase Authentication نیاز دارد. دامنه `denon313.github.io` باید در `Authentication → Settings → Authorized domains` ثبت باشد. قوانین Firestore/Storage را جداگانه و محدود تنظیم کن؛ صرفاً افزودن دامنه به معنی ایمن شدن داده‌ها نیست.

## محدودیت‌های این نسخه
- ورودی صوتی از Web Speech API مرورگر استفاده می‌کند و در همه مرورگرها/زبان‌ها یکسان نیست.
- سابقه گفتگو روی همان دستگاه ذخیره می‌شود؛ همگام‌سازی ابری تاریخچه در این نسخه پیاده‌سازی نشده.
- جست‌وجوی وب Gemini فقط در صورت پشتیبانی Google Search grounding از طرف مدل/API فعال است.
- کلیدهای API در مرورگر برای استفاده شخصی‌اند و در وب‌سایت عمومی محرمانه محسوب نمی‌شوند.
